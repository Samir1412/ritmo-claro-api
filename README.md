# Ritmo Claro API

Ritmo Claro es una microempresa que esta orientada al bienestar corporativo que acompaña a equipos remotos en la adopción de hábitos saludables, como la meditación y las pausas activas. Hoy el flujo de trabajo que manejan es manual y de forma descentralizada: los hábitos de los participantes se registran y se terminan por gestionar en formularios y hojas de cálculo compartidas, sin un punto único y controlado para toda la información. Este método genera tres problemas: correos duplicados, estados escritos de diferentes maneras que vuelven inconsistentes a todos los datos, y un riesgo de privacidad, porque una persona podría consultar o modificar información que no le pertenece. Además, el sistema actual solo funciona en el computador de quien lo desarrolló y no cuenta con documentación estable, lo que impide integrarlo con una futura aplicación web.

Este proyecto es una API REST modular construida con Node.js y NestJS, que guarda los datos en PostgreSQL mediante Prisma, protege el acceso con autenticación JWT (Passport y bcrypt), documenta su contrato con Swagger en `/docs` y se empaqueta con Docker para publicarse en una URL pública. Un visitante puede registrarse con un email único, lo que crea una cuenta con rol USUARIO, e iniciar sesión para obtener su token. Un USUARIO (participante) puede crear, consultar, editar y eliminar sus propios hábitos de forma privada. Un ADMIN (soporte) administra sus propios hábitos y además puede consultar los hábitos de todas las personas registradas. El MVP no incluye frontend, aplicación móvil ni panel administrativo visual; tampoco recordatorios, rachas, estadísticas, notificaciones, pagos, funciones de inteligencia artificial ni recuperación de contraseña. Además, no existe una ruta pública para elegir o cambiar el rol: el rol ADMIN se asigna fuera del flujo de registro.
